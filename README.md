# Server Rack Builder

Plan a quiet, rolling plywood cabinet for 19-inch servers from the stock you already have.

Enter your plywood sheets, planks and devices. The page works out:

- **Cabinet size** from the devices, sound lining (dense fiber + foam), intake and exhaust chambers, and caster height.
- **A numbered cut plan** for each sheet. Layouts are guillotine-only, so every cut runs edge to edge and a circular saw can make all of them. Kerf is included.
- **Plank fallback.** Any panel that doesn't fit on a sheet is built from plank strips with battens. Planks marked "with nails" are used last and flagged.
- **An exploded 3D model** (three.js) with assembled, exploded and cutaway views, an explode slider, layer toggles and tap-to-inspect. Parts are colored by material: plywood sheet, plywood plank, steel, aluminum, dense fiber and foam.

Settings are saved in the browser. Everything runs client-side; there is no backend.

Live: https://rackbuilder.privatecomputesystems.com

## Airflow design

Intake comes up through a slot in the bottom panel at the front, into a chamber in front of the device faces. Exhaust goes into a rear chamber, out under the back panel and through optional top fans. Sound has to turn corners to get out; air doesn't mind.

## Project layout

```
src/index.fragment.html   page markup and styles (also published as a Claude artifact)
public/solver.js          dimensions, sheet packing, plank packing, 3D part list (pure, tested)
public/render.js          three.js viewer
public/app.js             UI wiring
public/index.html         generated by `npm run build` from the fragment
scripts/build.mjs         wraps the fragment into a full HTML document
test/                     node:test suites for the solver and the 3D model
wrangler.jsonc            Cloudflare Worker (static assets) + custom domain
```

## Develop

```sh
npm install
npm test
npm run dev        # build + wrangler dev
```

## Deploy (Cloudflare Workers)

The custom domain `rackbuilder.privatecomputesystems.com` is declared in `wrangler.jsonc`, so the first deploy creates the DNS record and certificate, as long as `privatecomputesystems.com` is a zone in the same Cloudflare account.

**Connect the repo (recommended):** Cloudflare dashboard → Workers & Pages → Create → Import a repository → pick this repo.

- Build command: `npm run build`
- Deploy command: `npx wrangler deploy`

**Or deploy from your machine:**

```sh
npx wrangler login
npm run deploy
```
